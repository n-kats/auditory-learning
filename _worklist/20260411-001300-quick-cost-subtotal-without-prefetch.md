# 2026-04-11 先読みを除く合計表示

## 目的
- コスト表の合計行の下に、先読みを除いた合計を表示する。

## 反映内容
- フロントエンドのコスト表に `時間（先読み除く）` 列を追加した。
- バックエンドのコスト集計は、各コスト行と合計行の `時間（先読み除く）` を、`next` 要求の受付時刻を境に返せるようにしている。
- 表示は `種類 / 時間 / 時間（先読み除く） / 費用` の4列構成にした。
- 合計は `計算中` にせず、その時点の集計値を返すようにした。

- frontend の `npm test` が通過。
- frontend の `npx tsc --noEmit` が通過。
- backend の `pytest tests/test_quick_auditory_learning.py` が通過。
